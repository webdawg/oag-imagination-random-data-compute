### What this establishes

- **Parallel layer, not a layer up.** `oag-imagination-random-data-compute` sits beside
  `oag-mesh`, both on top of `open-agent-graph`. It does not rebuild foundational items: it uses
  `oag`'s event log, replication, signing, and tensor pads.
- **No configuration, ever.** The layer is an algorithm that runs continuously.
- **It powers the constant movement of `open-agent-graph`.** It is an engine that keeps connecting
  and keeps things moving.
- **The request can be anything.** Connect to a legacy server (https), a communication request to
  a node, an API spend, storing information. The possibilities are infinite.
- **Routing is guided by the tensor pads.** The fan-out is routed through the tensor pads that
  guide and connect everything at each individual node. The nodes learn to behave how the clients
  need them to.
- **Each node drops a random message or real data** as part of constructing the request.
- **Randomness sources are open.** Muon detectors, answers to questions -- the hardware interface
  is still to be figured out.
- **It can serve anything.** A piece of data, the actual answer to the request.
